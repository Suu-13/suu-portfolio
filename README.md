# Suu Wutt Yee Hnin: Portfolio

Static site (plain HTML, CSS, JS). No build step.

## Edit your information
Open `js/data.js`. Change the text between the quotes. To add a job, school or project, copy one `{ ... },` block and paste it below.
Put your photo in `images/` and set `photo: "images/profile.jpg"`. Put your resume PDF in `documents/` and set `resume`.

## Publish on GitHub Pages
1. Create a repo named `YOUR-USERNAME.github.io` and upload all these files.
2. Repo Settings > Pages > deploy from the `main` branch, root folder.
3. Your site appears at `https://YOUR-USERNAME.github.io/`.

## Preview locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.
